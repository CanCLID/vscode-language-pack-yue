# Cantonese Language Pack for Visual Studio Code

Natural Hong Kong Cantonese (`yue`) for the Visual Studio Code interface. Install it from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=CanCLID.vscode-language-pack-yue), then choose **Configure Display Language** in VS Code.

Maintainers: edit only `translations/corpus.yue.json`, run `node scripts/release-generate.mjs`, then `node scripts/validate.mjs`. The style guide and terminology policy are under `docs/` and `terminology/`. Use the repository-local `update-vscode-language-pack` skill for corrections and VS Code baseline updates.
