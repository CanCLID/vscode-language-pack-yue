# Cantonese Language Pack for VS Code

Cantonese Language Pack 為 VS Code 提供香港粵語介面。

## 用法

你可以用 **Configure Display Language** 指令設定 VS Code 嘅顯示語言。撳 `Ctrl+Shift+P` 開啟 **Command Palette**，輸入 `display`，再揀 **Configure Display Language**。喺語言清單揀「粵語」之後，重新啟動 VS Code 就得。

詳情請睇 [VS Code 文件](https://go.microsoft.com/fwlink/?LinkId=761051)。
